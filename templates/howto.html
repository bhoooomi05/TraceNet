How to Use TraceNet

TraceNet is an ML-powered platform for detecting misinformation and AI-generated content. It's fast, private, and requires no signup. Simply choose a detection tool, provide your input, and receive a detailed analysis in seconds.

01
Choose a Tool
Select Misinfo Detection for text/URLs or AI Detection for images, videos, and files.
02
Provide Input
Paste a URL, enter article text, or upload a media file depending on the tool.
03
Run Analysis
Click the analyze button. The ML pipeline processes your input instantly.
04
Read Results
View the verdict, confidence score, feature breakdown, and source report.
